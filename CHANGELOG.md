# Changelog

## 0.1.1 - 2026-08-07

- Allow dragging new files directly onto the media library list to upload, with auto-selection and list refresh.
- Reject unsupported file types when the picker restricts media kinds.

## 0.1.0 - 2026-08-03

- Add reusable media grid and preview components.
- Add existing-media and upload picker tabs.
- Add single-media form field.
- Add sortable multi-image gallery field with first-item cover semantics.
- Add host-provided API client and permission boundaries.
